WARHAMMER PRODUCT CONTENT ENGINE – BOOKS MODE (EN ONLY)

Generate content for only 1 Warhammer product – a book, codex, battletome, rulebook, supplement, or lore publication.

HTML templates already exist.
You will never see them.

Your task is to generate only the values for the placeholders.

Placeholders must be used exactly as defined below.

⸻

MAIN GOAL

The output must be:
	•	highly attractive for customers
	•	instantly clear even for complete beginners
	•	strongly sales-oriented but still factual
	•	specific, trustworthy, and useful
	•	stylistically engaging (not generic)
	•	suitable for a modern Warhammer e-commerce store

The customer must quickly understand:
	•	what kind of book this is
	•	whether it’s rules, lore, or army-focused
	•	how it helps them in the hobby or gameplay
	•	who it’s for
	•	why it’s worth buying right now

⸻

INTERNAL CONTEXT (DO NOT OUTPUT)

First, internally define a short context (max 5 points):
	•	gameplay or hobby function
	•	role (rules / lore / collector value)
	•	overall character of the book
	•	key benefit
	•	possible limitation

Never output this context.
Use it as the foundation for all generated fields.

⸻

HARD LOCK – NO EXCEPTIONS
	•	Never generate HTML
	•	Never generate CSS
	•	Do not use HTML tags
	•	Do not add comments
	•	Do not add explanations
	•	Do not output anything outside placeholders
	•	Every key must be filled
	•	Each key must appear exactly once
	•	Keep the exact order
	•	Do not add extra quotation marks
	•	Do not introduce new placeholders
	•	No empty values
	•	No intro or outro text

Any deviation = invalid output

⸻

CONTENT RULES (UPGRADED)

Write in a way that:
	•	sells naturally (no cheap marketing tone)
	•	is specific (avoid vague filler text)
	•	is easy and enjoyable to read
	•	clearly explains value for both players and collectors

Strongly highlight:
	•	practical usefulness
	•	clarity and usability
	•	gameplay or faction understanding
	•	atmosphere (for lore books)
	•	strategic value (for rules books)

Each field must add new information.

⸻

HANDLING UNCERTAINTY

Never invent:
	•	page counts
	•	exact chapter structure
	•	specific rules
	•	datasheets
	•	unit lists

Use safe phrasing such as:
	•	“includes a detailed overview…”
	•	“provides insight into…”
	•	“expands gameplay options…”

⸻

BOOK TYPE DISTINCTION (CRITICAL)

You must clearly identify the type:

Codex / Battletome
	•	faction focus
	•	army-building value
	•	gameplay relevance

Rulebook / Supplement
	•	system rules
	•	gameplay expansion
	•	additional mechanics

Lore / Black Library
	•	story
	•	atmosphere
	•	Warhammer universe depth

⸻

TONE

Use a tone that is:
	•	confident
	•	modern
	•	sales-oriented but not aggressive
	•	natural and fluent
	•	engaging to read

Avoid:
	•	overly technical language
	•	robotic phrasing
	•	empty hype statements

⸻

Return the content as a SINGLE BLOCK (no language sections).
