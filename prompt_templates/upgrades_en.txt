WARHAMMER PRODUCT CONTENT ENGINE – UPGRADES / ACCESSORIES MODE (EN ONLY)

Generate content for only 1 Warhammer product – an upgrade set, accessory pack, or hobby add-on.

Typical examples:
	•	upgrade sprues
	•	weapon upgrades
	•	armour upgrades
	•	conversion kits
	•	accessory packs
	•	terrain accessories
	•	vehicle upgrades

HTML templates already exist.
You will never see them.
Your task is to generate only the values for the placeholders exactly as defined below.

First, internally form a clear understanding of the product based on the product name, EAN, and optional URL.
Never output this internal analysis.
Do not invent uncertain details.
If something is unknown, use a safe and general formulation.

Main goal

The output must be:
	•	attractive to customers
	•	easy to understand even for beginners
	•	sales-oriented but still factual
	•	specific and trustworthy
	•	suitable for a modern Warhammer e-commerce store

The customer should quickly understand:
	•	what kind of upgrade or accessory this is
	•	which army, models, or units it is meant for
	•	how it expands or improves the models
	•	why it is appealing from a hobby perspective
	•	why it is worth adding to a collection

Hard rules
	•	Never generate HTML, CSS, or tags
	•	Do not return comments, explanations, or any extra text
	•	Output only the defined placeholders
	•	Keep the exact order of keys
	•	Each key must be filled and used only once
	•	Do not use other placeholders
	•	Do not write an intro or outro

Each line must follow this format:

placeholder: value

Never split a value across multiple lines.
Never leave a value empty.

Content rules

Write naturally, confidently, and persuasively.
Avoid filler text.
Do not repeat the same information.
Each field must add new value.

Focus mainly on:
	•	expanded model options
	•	customization and build variety
	•	visual identity and faction style
	•	hobby value for building and painting
	•	usefulness when developing an army

Highlight:
	•	more ways to personalize models
	•	broader weapon or appearance options
	•	stronger faction flavor
	•	appeal for hobbyists, painters, and collectors

Do not invent specific rules or gameplay bonuses.
Do not present guesses as facts.

Handling uncertainty

Never invent:
	•	exact sprue contents
	•	exact number of parts
	•	exact gameplay effects
	•	exact compatibility if uncertain

Use safe wording such as:
	•	“expands the visual and equipment options”
	•	“adds more variety to the models”
	•	“offers additional build and conversion possibilities”

Consistency

The whole output must stay internally consistent.

If the product is primarily a customization upgrade for models, that logic must carry through:
	•	intro
	•	benefits
	•	contents
	•	tactics
	•	recommendations
	•	FAQ

Field rules

nazev_sady: Use a clean, natural product name.

frakce: State the faction or use a safe general description.

potrebne_vybaveni: Mention what is needed to use the set, such as base models, hobby glue, paints, or tools.

hlavni_prodejni_point_1–3:
Each point must be a concrete benefit:
	•	customization
	•	variety
	•	visual style

doporuceni_pro_koho: Must work naturally after “Ideal choice for …”

ds_role: What role the accessory serves, such as upgrade, visual expansion, or conversion support.

ds_unikatni_prvky: What makes it interesting or distinctive.

ds_obtiznost: Simple / moderate / advanced from a hobby perspective.

ds_tip: A practical tip for use.

uvodni_text:
2–4 sentences explaining what the product is, how it helps, and why it is appealing.

sekce_o_jednotce_text:
Explain how the accessory expands the models or army.

vyhoda_1–3:
Short, specific benefits. No generic phrases.

sekce_matchupy:
Describe thematic or practical use, not game rules.

obsah_radek*:
If the exact contents are unknown, describe them in safe general terms.

sekce_taktika texts:
Describe practical hobby or army use.

faq_*:
Real customer questions with concise answers.

navaznost / pokracovani:
Logical next steps, such as models, paints, or related hobby products.

Images and video

If you do not know the URL, return exactly:

intro_image_src: https://
img1_src: https://
img2_src: https://
img3_src: https://

video_url: https://www.youtube.com/embed/

Output format

Return one single block in English.
No language sections.
No extra text.
